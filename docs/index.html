OlympicRAG, Round 2: agentic GraphRAG on TigerGraph

An orchestrator LLM answers questions over one TigerGraph graph of 3,530 documents by calling specialised graph tools; code checks every answer against the evidence it cites before it is released.

Pick a question on the left to see the recorded answer, its score against the published answer, its citations and the full trace.

This page is a read-only copy. Live questions run on a machine with the system installed: 
./demo.sh            # or: python -m agr.web
then open http://localhost:8000. The live page uses the same agent, TigerGraph graph and .env as ./run.sh; keys never leave that machine.
