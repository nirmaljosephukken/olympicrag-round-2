Layer 1 · the graph

Infoboxes, source-record headers and text are turned into typed vertices and edges by code; no LLM extracts facts, so no edge is invented. Hover a node for its count.

Layer 2 · the agent loop

How a question reaches a conclusion. The orchestrator sees the question, the tools and the evidence so far, and chooses one action per turn. Every proposed answer passes through code checks; a rejected answer goes back with the reason.

Layer 3 · what the checks enforce

Grounding (code)

Every name and number in the answer must be stated in an evidence item it cites; a bare count must come from a count field; a name paired with a medal must hold that medal. Uncited evidence that states the answer is cited automatically, and citations are trimmed to the items that state part of it.

Status (code)

The agent lists the facts the question asks for and marks each as stated or not. None stated → not_in_corpus, some → partial, all → answered. Before not_in_corpus is accepted, code searches every name in the question, runs a similarity search and reads the source records.

Completeness (code)

An answer that cites a full table (every edition of an event, every repeat winner) must include every row, or it is sent back with the rows it left out.

Evidence policy (prompt)

The most authoritative source for the time asked wins: signed decisions, juries, certificates > scoreboards, schedules, feeds > news > blogs, fans, volunteers. A later publication does not override a signed decision; registrations are not starters; missing evidence is not a negative fact.

Accuracy across runs

Strict fact-by-fact scoring against the published answers (partial credit per fact). An LLM judge re-scored the earlier fast-period run (06930bd) at 90.3% against 82.5% strict; the official score uses the organisers' key.

When does a question need an agent?

Same graph, same LLM, same 50 public questions. One-call pipelines lose most on counting, ranking, complete lists and trends, which the agent answers with tools that compute the result.
